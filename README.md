# سیستەمی پێشکەوتووی کاشێری و بەڕێوەبردنی چێشتخانەی شەهلا خان
## Modern Restaurant POS & Management System

سیستەمێکی تەواو مۆدێرن و فرەبەشە بۆ بەڕێوەبردنی چێشتخانە و فەست فوودەکان بە زمانی کوردی، بە دیزاینی ئاست بەرز (Glassmorphism & Dark Mode) و تەکنەلۆژیای سەردەمیانە.

---

### ✨ تایبەتمەندییە سەرەکییەکان (Features)

1. **شاشەی خێرای کاشێر (POS Terminal)**:
   - پشتیوانی جۆرەکانی داواکاری: 🍽️ لە ناوەوە (سەرمێز)، 🥡 بردنەدەرەوە، 🛵 گەیاندن (Delivery).
   - نەخشەی مێزەکان و دیاریکردنی مێزی میوانان.
   - گەڕانی خێرا و فلتەری پۆلەکان بە ئایکۆن و ژمارەی کاڵا.
   - بەشی ڕاگرتنی داواکاری لە سەبەتە (Hold & Retrieve Order).
   - حیسابکردنی داشکاندن (% یان بڕی جێگیر بە دینار).
   - حیسابکردنی بڕی پارەی گەڕاوە (Change Calculator) بە دوگمەی خێرا.
   - شێوازی پارەدانی جۆراوجۆر: کاش، FastPay، FIB، ZainCash، کارتی بانکی، و قەرز.

2. **وەسڵی گەرمی و وەسڵی چێشتخانە (Receipt & KOT Printing)**:
   - پێشبینینی ڕاستەوخۆی وەسڵی گەرمی 80mm/58mm بە بارکۆدی کوردی.
   - دەرکردنی پسوڵەی چێشتخانە (Kitchen Order Ticket - KOT) تایبەت بە چێشتلێنەران.

3. **بەشی کۆگا و کەرەستە خاوەکان (Storage & Inventory)**:
   - تۆمار و بەڕێوەبردنی هەموو ماددە سەرەکییەکان (گۆشت، نان، پەتاتە، پەنیر، ڕۆن، ساردەمەنی، هتد).
   - ئاگاداری کەمبوونەوەی کاڵا (Low Stock Alert).
   - تۆمارکردنی باری نوێ (Restock) و کەمکردنەوەی بەفیڕۆچوون (Waste).
   - خەمڵاندنی بەهای دارایی هەموو کۆگا.

4. **دەفتەری قەرز و کڕیاران (Customer Debt Ledger)**:
   - لیستی کڕیارانی بەردەوام، ناونیشان و ژمارەی مۆبایل.
   - تۆمارکردنی قەرز و وەرگرتنەوەی پارە لەگەڵ مێژووی وەرگرتن.

5. **مەسرەف و خەرجی ڕۆژانە (Expenses Tracker)**:
   - تۆمارکردنی پسوڵەکانی مەسرەف (مۆلیدە، کارەبا، کڕینی ڕۆژانە، مووچە، کرێ).
   - پۆلێنکردن بەپێی بەشەکان.

6. **یاریدەدەری زیرەکی دەستکرد (Kurdish AI Assistant & Insights)**:
   - گفتوگۆی ژیرانە بە زمانی کوردی لەسەر قازانج، کاتە قەرەباڵغەکان، کۆگا و پێشنیاری بەرزکردنەوەی فرۆش.
   - دیاریکردنی جووتە خواردنە پڕفرۆشەکان (Smart Combos).
   - شیکاری کاتژمێرە پڕفرۆشەکانی شەو و ڕۆژ.

7. **ڕاپۆرتە داراییەکان و هەناردەکردن (Reports & Export)**:
   - فلتەرکردنی بەروار (ئەمڕۆ، دوێنێ، حەفتانە، مانگانە، مەودای دیاریکراو).
   - هەناردەکردنی هەموو داتاکان بۆ فایلی CSV / Excel.
   - خەمڵاندنی قازانجی پوخت: `فرۆشی گشتی - تێچووی ماددە خاوەکان - مەسرەف`.

8. **ڕێکخستنەکان و پاراستنی داتا (Settings & Backup)**:
   - گۆڕینی ناسنامەی چێشتخانە و ناونیشان.
   - دەنگی کلیک و کاشێری چالاک (Web Audio API).
   - هەناردەکردن و هاوردەکردنی داتا (JSON Backup & Restore).
   - دەستپێک و داخستنی وەجبەی دەوام (Shift Management).

---

### 🛠️ تەکنەلۆژیاکانی بەکارهاتوو (Tech Stack)
- **React 19**
- **Vite 7**
- **Tailwind CSS 4**
- **FontAwesome & Lucide Icons**
- **Canvas Confetti**
- **Web Audio API**
- **Kurdish Typography (Vazirmatn & Noto Naskh Arabic)**

---

### 🚀 ڕێنمایی کارپێکردن (Running Locally)

```bash
# دابەزاندنی پێداویستییەکان
npm install

# دەستپێکردنی سێرڤەری لۆکاڵ
npm run dev

# درووستکردنی وەشانی بەرهەمهێنان (Production Build)
npm run build
```
